Cómo se conectan sus partes

La relación entre el navegador, el servidor y la base de datos.

Tres partes conectadas

El navegador
Es la pantalla de AzChat que utiliza cada persona, desde una computadora o un celular.
El servidor en Render
Comprueba los accesos, atiende las acciones del chat y comunica los mensajes nuevos.
La base de datos en Supabase
Conserva cuentas, conversaciones, mensajes y sesiones para las siguientes consultas.

Un ejemplo de conexión

Cuando una persona envía un mensaje, su navegador se comunica con el servidor. El servidor lo guarda en la base de datos y avisa a los dos participantes. El navegador no se conecta directamente a la base de datos.

Archivo editable de Draw.io

Alojamiento para la demostración

La demostración comenzará con servicios gratuitos. Se acepta la espera de arranque del servidor después de la inactividad; la prueba de recepción de mensajes se hará con el servidor ya activo.
