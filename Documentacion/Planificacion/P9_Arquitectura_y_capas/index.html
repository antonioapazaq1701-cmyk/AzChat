Cómo se conectan sus partes

La relación entre el navegador, el servidor y la base de datos.

Arquitectura propuesta

Parte propuestaResponsabilidad
NavegadorHTML, CSS y JavaScript para presentar los formularios y las conversaciones.
Servidor de aplicaciónNode.js y Express para atender solicitudes y aplicar reglas de acceso.
PersistenciaPostgreSQL administrado en Supabase para conservar cuentas, conversaciones y mensajes.
Servicio de correoProveedor externo para entregar códigos y solicitudes de autorización.
Portal de planificaciónGitHub Pages para consultar estos documentos y bocetos estáticos.

Intercambio entre las partes

El navegador se comunicará con el servidor mediante HTTPS. Solo el servidor accederá a la base de datos y al servicio de correo. Para mostrar novedades se propone consultar cambios periódicamente, sin recargar toda la pantalla.

Criterios de protección y alojamiento

Las credenciales de la base y del correo deberán permanecer en configuración privada. Los permisos se comprobarán por cuenta y conversación. Se prevé alojar el servidor en Render; si se elige un plan con suspensión por inactividad, la evaluación deberá distinguir la espera de arranque del tiempo normal de respuesta.
