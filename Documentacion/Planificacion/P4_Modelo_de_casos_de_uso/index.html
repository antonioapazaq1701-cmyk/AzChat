Las acciones de cada persona

Cómo se relacionan las personas con la aplicación.

Casos de uso en contexto

CasoRecorrido y resultado
Preparar una entregaUna persona abre el chat de su equipo, adjunta el avance y responde a una observación. El intercambio queda en el historial del grupo.
Organizar un grupoSu administrador incorpora o retira miembros. Si desea salir, debe dejar otro administrador cuando aún quedan participantes.
Personalizar un contactoUna persona guarda un nombre que le resulta fácil reconocer. El perfil original y la vista de las demás cuentas se mantienen.
Recuperar accesoLa persona indica la cuenta y el correo. Si ese correo ya estaba confirmado, puede verificarlo; si es nuevo, primero requiere revisión del responsable. Después del código válido confirma una nueva contraseña.

Qué representa un caso de uso

Describe un objetivo de la persona y el resultado que obtiene. La lista de funciones pertenece al catálogo; aquí se muestra cómo se combinan para completar una tarea.
