Las reglas del chat

Qué datos se aceptan y cómo se comprobará el funcionamiento.

Al crear una cuenta

Nombre completo
Se solicitan los nombres y apellidos. En los chats se mostrará el nombre de usuario.
Código de estudiante
Debe tener exactamente 6 dígitos. Se conserva como texto para mantener ceros iniciales, por ejemplo 012345.
Nombre de usuario
Debe tener de 3 a 20 caracteres, comenzar por una letra y utilizar letras, números o guion bajo. No distingue mayúsculas.
Contraseña
Debe tener al menos 8 caracteres. La recuperación y el cambio de contraseña quedan fuera de esta versión.

Al conversar

  • Se busca el nombre de usuario completo, sin coincidencias parciales.
  • No se permite crear un chat consigo mismo. Si la pareja ya tiene un chat, se abre ese mismo historial.
  • Cada mensaje admite entre 1 y 1000 caracteres. Un texto formado solo por espacios se rechaza.
  • Se confirma el envío después de guardar el mensaje. Un reintento no debe crear otra copia.
  • El texto de un envío fallido se conserva mientras la página siga abierta. El reintento se hace al pulsar un botón.

Cómo se comprobará

Las pruebas cubrirán cuentas válidas e inválidas, privacidad, mensajes, desconexiones, historial y lectura en celular. La prueba de capacidad usará 30 personas en 15 parejas, durante 2 minutos, enviando un mensaje por persona cada 10 segundos.

Con el servidor activo y conexión estable, cada mensaje deberá aparecer en su destinatario en un máximo de 3 segundos. Estos resultados se medirán durante la construcción.
