Planificación del proyecto

Un chat privado para estudiantes

AzChat es una propuesta de mensajería web sencilla. Esta presentación explica qué se quiere construir y cómo se ha organizado el trabajo.

Explorar los 12 pasos

¿Qué es AzChat?

Una aplicación web prevista para conversar entre dos personas mediante mensajes de texto. Funcionará en computadora y celular, y permitirá volver a consultar el historial.

  • Acceso sencilloCada persona podrá registrarse e ingresar con su usuario o código de estudiante.
  • Conversaciones privadasSe buscará a la otra persona por su nombre de usuario exacto y se abrirá un único chat por pareja.
  • Mensajes conservadosLos mensajes se guardarán para que ambos participantes puedan consultarlos después.

Se prevé empezar con hasta 4 personas y comprobar una meta de 30 conectadas. La primera versión no incluye grupos, archivos ni llamadas y no tendrá cifrado de extremo a extremo.

Estado: la planificación está documentada. La aplicación real y las pruebas de capacidad se realizarán durante la construcción.

Cómo se trabajará

El proyecto emplea una metodología Ágil: se organiza en entregas pequeñas, se revisa cada resultado y se ajusta antes de continuar. La planificación puede actualizarse cuando las pruebas o las necesidades lo requieran.
